# Head AI Beta Testing Guide

Thank you for participating in the Head AI beta testing program! Your feedback is invaluable in helping us improve the application.

## Quick Start

1. **Installation**:
   - Run `launch_monitor.bat` to start the server monitor
   - The system tray icon will appear in the bottom right
   - Use the tray icon menu to start/stop the server

2. **Server Status Colors**:
   - 🔴 Gray: Server is off
   - 🔵 Blue outline: Server is idle
   - 🟢 Solid green: Server is active

## Beta Features

- **Module Marketplace**: Install and manage AI modules
- **Auto-Learning**: Adaptive learning capabilities
- **Performance Monitoring**: Real-time system metrics

## Providing Feedback

1. **In-App Feedback**:
   - Click the feedback icon in the system tray
   - Select a category
   - Provide your feedback
   - Attach screenshots if relevant

2. **Issue Reporting**:
   - For bugs, use the "Report Issue" option
   - Include steps to reproduce
   - Crash reports are automatically collected

3. **Feature Requests**:
   - Use the "Feature Request" form
   - Be specific about use cases
   - Include priority level

## Beta Testing Focus Areas

1. **Installation Process**:
   - Installation smoothness
   - System requirements
   - Configuration setup

2. **Core Functionality**:
   - Server stability
   - AI response quality
   - Learning capabilities

3. **User Experience**:
   - Interface intuitiveness
   - System tray integration
   - Performance impact

4. **Module System**:
   - Module installation
   - Update process
   - Module compatibility

## Known Issues

1. First-time server start may take longer
2. Some modules require manual configuration
3. Auto-update requires system restart

## System Requirements

- Windows 10/11
- Python 3.8 or higher
- 4GB RAM minimum
- 2GB free disk space

## Privacy Notice

During beta testing, we collect:
- Usage statistics
- Performance metrics
- Error logs
- System information

You can opt-out of data collection in settings.

## Updates

The app will check for updates daily. You can:
- Enable auto-updates
- Choose update channels (beta/stable)
- Schedule update times

## Uninstallation

1. Stop the server
2. Run uninstall.bat
3. Delete the installation directory

Your participation helps make Head AI better. We appreciate your time and feedback!
